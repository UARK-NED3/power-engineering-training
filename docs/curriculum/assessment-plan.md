# Assessment Plan

Assessment checks whether the learner can connect physical mechanisms to evidence. It does not assess access to restricted hardware.

| Checkpoint | Evidence | Technical standard |
| --- | --- | --- |
| System map | Annotated electrical, thermal, control, and measurement paths | Defines a system boundary and labels assumptions |
| Loss estimate | Hand calculation or code notebook | Uses units, defines operating point, and reports validity limits |
| Package-function sketch | Original generic cross section | Connects features to electrical, thermal, and mechanical functions |
| Thermal model | Steady-state or transient network | Passes dimensional and limiting-case checks |
| Measurement plan | Instrument and uncertainty table | Separates sensor reading from inferred quantity |
| Test or simulation plan | One-page plan | Identifies baseline, variables, response, hazards, and stop conditions |
| Final mini-project | Report and short presentation | Distinguishes measured, simulated, derived, and proposed conclusions |

## Feedback questions

1. What physical quantity is the conclusion about?
2. What observation, calculation, or model supports it?
3. Which assumptions control the result?
4. What plausible alternative explanation remains?
5. What next measurement or analysis would most reduce that uncertainty?
