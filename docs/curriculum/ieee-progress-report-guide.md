# IEEE Progress Report Guide

## Submission status

This guide prepares a concise technical progress report. Before submission, the faculty sponsor must confirm the current IEEE EPS reporting template, page limit, required fields, portal, deadline, and whether public release approval is required. This repository does not claim that a particular format or deadline applies to the current program cycle.

## Recommended report structure

### Title and project context

State the power-module cooling or packaging question in plain language. Do not include confidential module identifiers, restricted drawings, student ID, phone number, or unpublished partner-laboratory information.

### Objective and hypothesis

Define the engineering objective, system boundary, expected mechanism, and the result that would support or challenge the hypothesis.

### Training and methods

Briefly summarize the study completed, non-energized practice, supervised station work, and analysis method. Identify the approved station only at the detail level permitted by its owner. State what was measured, derived, simulated, or inferred.

### Results

Use one original system figure or plot and one compact results table. Label all axes with symbols and units. State independent-run count and uncertainty or variability representation. A result can be preliminary when the evidence class and limitation are explicit.

### Discussion and next step

Explain the physical meaning of the observed response. State at least one limitation and one next measurement, analysis, or test condition that would reduce uncertainty. Do not claim junction temperature, reliability, or module qualification without evidence appropriate to that claim.

### Acknowledgment and references

Acknowledge approved support in language accepted by the sponsor. Cite public study sources, approved datasheets, and other permissible references. Do not reproduce or cite restricted 2025 program files as report figures or sources.

## Submission readiness checklist

- [ ] Faculty sponsor confirmed current IEEE EPS requirements and submission route.
- [ ] All numerical claims have units and evidence classes.
- [ ] Every figure is original or has explicit public reuse permission.
- [ ] The report excludes student personal information and restricted laboratory content.
- [ ] The report distinguishes module-under-power evidence from non-energized, simulated, or illustrative work.
- [ ] Mentor reviewed the final technical claims, limitations, and acknowledgments.
- [ ] The submitted file and submission confirmation are retained in the approved private location.
