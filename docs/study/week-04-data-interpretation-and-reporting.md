# Week 4 Study Guide: Comparison, Uncertainty, and Progress Reporting

## Core idea

A contrast condition should test one mechanism. A lower measured temperature difference supports an improved external thermal path only if the assigned electrical loss, reference condition, mounting state, and analysis method are sufficiently controlled.

## Comparison logic

Start with one detailed baseline. Change one owner-approved cooling-boundary condition. Report the result for every independent run, then summarize the mean and variability only when the repeats represent comparable independent trials.

A valid comparison answers four questions:

1. What changed?
2. What was controlled or monitored?
3. What quantity changed in response?
4. How certain is the observed difference?

A result with no detectable change remains useful. It may indicate a small physical effect, inadequate measurement resolution, competing heat paths, a changed loss condition, or incomplete stabilization. The student should state which explanation the evidence favors and what next test could separate them.

## Evidence language

Use measured for a direct sensor output, derived for a calculation from measured inputs, simulated for a model output, inferred for a conclusion supported indirectly, and proposed for a future action. Do not use a derived case temperature to claim a measured junction temperature.

## Practice task

Create a comparison table with condition, independent-run count, P_loss, T_case, T_ref, R_theta,case-ref, uncertainty or sensitivity range, and notes. Draft a conclusion that contains one result, one limitation, and one next step.

## Self-check

- Can a lower T_case alone demonstrate lower thermal resistance?
- Which variables must be comparable before R_theta values are compared?
- What conclusion is supported by a result that overlaps the uncertainty or variability range?
- Which figures and data can be included in a public report, and which need owner approval?
